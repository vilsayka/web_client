# QA-документация проекта VibeCore

Папка содержит артефакты контроля качества:

- `test_plan.md` - стратегия и границы тестирования.
- `checklist.md` - чек-лист ручного и регрессионного тестирования.
- `test_cases.md` - тест-кейсы для API, сервисов и frontend.
- `test_report.md` - отчет о выполненном тестировании.

Автотесты находятся в папке `tests/` и документированы docstring-описаниями на русском языке.

Команда запуска:

```powershell
python -m unittest discover -s tests -p "test*.py" -v
```
