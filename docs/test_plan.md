# Тест-план

## Цель

Проверить качество проекта VibeCore до передачи пользователю: API, бизнес-логику, валидацию данных, базовые frontend-сценарии и регрессионную стабильность.

## Объект тестирования

- Backend API `/api/v1`.
- Сервисы пользователей, комплектующих, заказов, гарантий и совместимости.
- Pydantic-схемы входных данных.
- JWT-аутентификация и проверка ролей.
- Наличие ключевых HTML-страниц и JS-функций frontend.

## Подход

- Ручная проверка покрыта чек-листом.
- Автотесты написаны на `unittest`, чтобы не зависеть от дополнительного тестового фреймворка.
- API-тесты используют `fastapi.testclient.TestClient`.
- Подключение к реальной БД заменено dependency overrides и mock-объектами.
- Найденные дефекты оформлены в Issues.

## Критерии входа

- Установлены зависимости из `requirements.txt`.
- Переменная `SECRET_KEY` задана в окружении или тесты используют безопасное тестовое значение.
- Запуск выполняется из корня проекта.

## Критерии выхода

- Все автотесты проходят.
- Для найденных дефектов есть описание, ожидаемое поведение и label.
- Регрессионный чек-лист готов для ручного прогона перед релизом.

## Риски

- Интеграционные тесты PostgreSQL БД не выполнялись!
