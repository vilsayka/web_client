# Чек-лист QA

## Аутентификация

- [ ] Пользователь регистрируется с валидными логином и паролем.
- [ ] Регистрация с уже занятым логином возвращает ошибку.
- [ ] Логин с валидными учетными данными возвращает Bearer-токен.
- [ ] Логин с неверным паролем возвращает 401.
- [ ] Refresh возвращает новый токен для валидного токена.
- [ ] Защищенные ручки не доступны без Bearer-токена.

## Комплектующие и сборка

- [ ] Список всех комплектующих возвращается сгруппированным по категориям.
- [ ] Фильтр по русской категории возвращает только нужный тип комплектующих.
- [ ] Неизвестная категория возвращает 400.
- [ ] Проверка совместимости возвращает `compatible=true` для корректной сборки.
- [ ] Проверка совместимости находит конфликт сокета CPU/материнской платы.
- [ ] Проверка совместимости находит конфликт RAM/материнской платы.
- [ ] Проверка совместимости находит недостаточную мощность блока питания.
- [ ] Проверка совместимости находит неподдерживаемый форм-фактор корпуса.

## Заказы

- [ ] Customer создает заказ из существующих комплектующих.
- [ ] Создание заказа с несуществующим компонентом возвращает 404.
- [ ] Customer видит свои заказы.
- [ ] Importer видит доступные заказы.
- [ ] Customer не видит список доступных заказов сборщика.
- [ ] Importer принимает свободный заказ.
- [ ] Importer не может принять уже занятый заказ.
- [ ] Статус меняется только по цепочке: `ожидает сборщика` -> `на сборке` -> `собрана`.
- [ ] Importer не может менять чужой заказ.

## Гарантии

- [ ] Customer создает гарантийное обращение по своему завершенному заказу.
- [ ] Customer не может создать обращение по чужому заказу.
- [ ] Обращение по незавершенному заказу возвращает 400.
- [ ] Нельзя указать компонент, который не входит в заказ.
- [ ] Описание проблемы короче 10 символов отклоняется.

## Frontend

- [ ] Страница входа открывается.
- [ ] Страница регистрации открывается.
- [ ] Страница сборки ПК открывается.
- [ ] Страницы заказов и гарантий открываются.
- [ ] JS-запросы используют префикс `/api/v1`.
- [ ] Сообщения пользователю отображаются на русском без битой кодировки.

## Регресс перед релизом

- [ ] Выполнить полный автотестовый прогон.
- [ ] Вручную пройти основные роли: customer, importer, admin.
- [ ] Проверить работу с реальной БД на тестовом стенде.
- [ ] Проверить, что все открытые дефекты имеют статус или решение.
