# Чек-лист QA

## Аутентификация

- [x] Пользователь регистрируется с валидными логином и паролем.
- [x] Регистрация с уже занятым логином возвращает ошибку.
- [x] Логин с валидными учетными данными возвращает Bearer-токен.
- [x] Логин с неверным паролем возвращает 401.
- [x] Refresh возвращает новый токен для валидного токена.

## Комплектующие и сборка

- [x] Список всех комплектующих возвращается сгруппированным по категориям.
- [x] Фильтр по русской категории возвращает только нужный тип комплектующих.
- [x] Неизвестная категория возвращает 400.
- [x] Проверка совместимости возвращает `compatible=true` для корректной сборки.
- [x] Проверка совместимости находит конфликт сокета CPU/материнской платы.
- [x] Проверка совместимости находит конфликт RAM/материнской платы.
- [x] Проверка совместимости находит недостаточную мощность блока питания.
- [x] Проверка совместимости находит неподдерживаемый форм-фактор корпуса.

## Заказы

- [x] Customer создает заказ из существующих комплектующих.
- [x] Создание заказа с несуществующим компонентом возвращает 404.
- [x] Customer видит свои заказы.
- [x] Importer видит доступные заказы.
- [x] Customer не видит список доступных заказов сборщика.
- [x] Importer принимает свободный заказ.
- [x] Importer не может принять уже занятый заказ.
- [x] Статус меняется только по цепочке: `ожидает сборщика` -> `на сборке` -> `собрана`.
- [x] Importer не может менять чужой заказ.

## Гарантии

- [x] Customer создает гарантийное обращение по своему завершенному заказу.
- [x] Customer не может создать обращение по чужому заказу.
- [x] Обращение по незавершенному заказу возвращает 400.
- [x] Нельзя указать компонент, который не входит в заказ.
- [x] Описание проблемы короче 10 символов отклоняется.

- [x] Страница регистрации есть в проекте.
- [x] Страница сборки ПК есть в проекте.
- [x] Страницы заказов и гарантий есть в проекте.
